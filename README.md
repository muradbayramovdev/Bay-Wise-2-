# Robot Lab 🤖

A web interface for presenting a robotics laboratory and its projects.

🔗 **Live Demo:** [robo-lab.netlify.app](https://robo-lab.netlify.app/)

## 📚 About This Project

Robot Lab is an **educational and mentorship project**. It was built by a junior student as part of a hands-on web development learning process, under the technical mentorship of **Murad Bayramov**.

My role was **mentor and reviewer**: teaching web fundamentals, planning the structure, giving UI/UX direction, and reviewing the code. The implementation itself was done by the student.

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript

## 📄 Pages

- `index.html`: Home page
- `project.html`: Projects page
- `resume.html`: Resume page

## 👥 Credits

## 🚀 Run Locally

No build step is required. Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/muradbayramovdev/Robot_lab.git
cd Robot_lab
```
